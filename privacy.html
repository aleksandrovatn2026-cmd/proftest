Политика конфиденциальности

Дата последнего обновления: 31 мая 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности регулирует порядок обработки персональных данных пользователей сервиса ПрофТест, доступного по адресу proftest-podrostki.vercel.app и в Telegram-боте @proftest_ru_bot.

Оператором персональных данных является самозанятый гражданин Российской Федерации (далее — Оператор). Обработка персональных данных осуществляется в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Какие данные мы собираем

При использовании сервиса мы собираем только следующие данные, необходимые для формирования персонального отчёта:

  • Имя (вводится пользователем самостоятельно)
  • Класс обучения (7–11)
  • Город проживания
  • Пол (для подбора персонажа)
  • Ответы на вопросы теста (20 вопросов)
  • Идентификатор Telegram (chat_id) — для доставки отчёта

Мы не собираем: паспортные данные, номера телефонов, адреса электронной почты, данные банковских карт (платёж обрабатывается сервисом ЮKassa).

3. Цели обработки данных

Собранные данные используются исключительно для:

  • Формирования персонального профориентационного отчёта
  • Доставки отчёта пользователю в Telegram
  • Улучшения качества сервиса (в обезличенном виде)

4. Хранение и защита данных

Данные хранятся на защищённом сервере. Мы принимаем технические и организационные меры для защиты персональных данных от несанкционированного доступа, изменения, раскрытия или уничтожения.

Ответы на вопросы теста используются только для генерации отчёта и не сохраняются в исходном виде после его создания.

5. Передача данных третьим лицам

Мы не передаём персональные данные пользователей третьим лицам, за исключением:

  • Сервиса ЮKassa — для обработки платежей (в соответствии с их политикой конфиденциальности)
  • Сервиса AI-генерации текста — для формирования персонального описания в отчёте (передаются только обезличенные данные: тип личности, баллы RISAC, класс, город — без имени и контактных данных)
  • Случаев, предусмотренных законодательством Российской Федерации

6. Права пользователей

Вы имеете право:

  • Запросить информацию о хранящихся данных
  • Потребовать удаления своих данных
  • Отозвать согласие на обработку персональных данных

Для реализации прав напишите нам в Telegram-бот @proftest_ru_bot.

7. Согласие на обработку данных

Начиная прохождение теста, пользователь подтверждает своё согласие на обработку персональных данных в соответствии с настоящей Политикой. Если тест проходит несовершеннолетний (до 18 лет), согласие даётся родителем или законным представителем.

8. Изменение политики

Оператор оставляет за собой право вносить изменения в настоящую Политику. Актуальная версия всегда доступна по адресу proftest-podrostki.vercel.app/privacy.

9. Контакты

По вопросам обработки персональных данных обращайтесь через Telegram-бот: @proftest_ru_bot
